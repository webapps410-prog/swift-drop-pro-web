Core Features

Everything you need,
nothing you don't.

Real-time Updates

Firebase Realtime Database keeps every order status synced instantly across all users — no refresh needed.

Order Tracking

Visual timeline from Placed → Confirmed → On the Way → Delivered. Customers always know where their order is.

Multiple Payments

UPI, Card, and Cash on Delivery — customers choose how they pay at checkout with a clean, intuitive UI.

3 User Roles

Shop owners manage products & orders. Customers browse & buy. Delivery agents accept and fulfil deliveries.

Secure Auth

Firebase Authentication keeps accounts safe. Role-based routing ensures each user only sees what they need.

Offline-ready Cart

Hive local storage keeps the cart available even without internet. Orders sync when back online.
